# Python String Palindrome

## Overview

This program checks whether a given string is a palindrome.

A palindrome is a string that remains the same when reversed.

## Example

Input:

malayalam

Output:

malayalam
malayalam
pali

## How It Works

The `rev()` function reverses the string by adding each
character to the beginning of the result.

The original string is then compared with its reversed form.

If both are the same, the string is considered a palindrome.
